# WD_P VLM and LLM experiment summary

## Scope and comparison rule

The target is **patient withdrawal (`WD_P`)**, using the 3RS v2022 boundary
`WD_P >= 2` for each human rater. The primary comparison uses identical physical
segments and patient-disjoint five-fold splits for both modalities:

- **VLM:** Qwen3-VL with 16 patient-only video frames per segment.
- **LLM:** Qwen3-8B Instruct with timestamped therapist/patient transcripts.
- **Primary classification threshold:** probability `>= 0.5`.
- **Consensus target:** both raters negative or both raters positive; disagreements excluded.
- **Soft target:** both negative = `0`, disagreement = `0.5`, both positive = `1`.

Results from different cohorts are retained for historical context, but they
must not be treated as paired modality comparisons.

### Diagnostic: effect of VLM positive-class weighting

| Repaired consensus VLM setup | Balanced accuracy | Recall | Specificity | Interpretation |
|---|---:|---:|---:|---|
| Automatic `pos_weight`, threshold 0.5 | 0.504 | 0.384 | 0.624 | Too conservative about positive WD_P |

The remaining 0.032 balanced-accuracy gap between the corrected repaired VLM
run and the historical one is consistent with the changed cohort and patient
folds. It should not be described as a pure model regression.

## Main findings

1. Transcript-role repair increased the common soft cohort from 1,151 to 2,457
   segments and the common consensus evaluation cohort from 796 to 1,734.
2. On repaired consensus folds, the LLM has higher balanced accuracy than the
   corrected VLM (`0.621` versus `0.574`), while the VLM has higher recall.
3. Consensus F1 is nearly identical (`0.728` LLM versus `0.725` VLM), but the
   models reach it with different error profiles: the VLM predicts WD_P very
   often and has low specificity.
4. With soft-label training, the LLM point estimate is also higher in balanced
   accuracy (`0.615` versus `0.585`).
5. Both patient-cluster bootstrap intervals include zero. Report the direction
   and size of the observed differences without claiming definitive patient-level
   superiority.
6. The repaired soft-label VLM result is at least as strong as its historical
   slide result (`0.585` versus `0.571`). The apparent consensus degradation was
   largely caused by the new automatic `pos_weight` default; setting it to `1`
   raised balanced accuracy from `0.504` to `0.574`.
